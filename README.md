# Skill-desarrollo-seguro
Skill de desarrollo seguro V0.5.4 es un sistema de desarrollo seguro para OpenAI Codex y Hermes Agent. Convierte la seguridad en una condición de finalización del cambio, no en una auditoría opcional al final.  La V0.5.4 comparte el mismo núcleo de seguridad entre ambos agentes y añade una integración nativa específica para cada uno.
