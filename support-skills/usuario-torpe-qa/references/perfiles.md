# Perfiles de prueba — Usuario Torpe QA

Usa estos perfiles como modelos de error humano plausible. No conviertas la prueba en ruido aleatorio y registra qué perfil provocó cada incidencia.

## Usuario que no lee

- Pulsa la acción visualmente más prominente sin leer textos de ayuda.
- Omite instrucciones extensas y tooltips.
- Interpreta etiquetas ambiguas por su significado cotidiano.
- Intenta continuar aunque exista una advertencia no bloqueante.

## Usuario impaciente

- Hace doble clic o pulsa varias veces mientras hay carga.
- Recarga si la respuesta tarda.
- Usa atrás/adelante durante estados intermedios.
- Repite un envío si no recibe feedback inmediato.

## Usuario sin experiencia digital

- Introduce datos con espacios accidentales, formatos habituales incorrectos o pegado desde otras aplicaciones.
- Confunde botones cercanos o acciones secundarias con la principal.
- Abandona y vuelve a un flujo sin entender su estado.
- Espera mensajes concretos y accionables cuando algo falla.

## Usuario destructivo accidental

- Pulsa eliminar, vaciar, restablecer o acciones masivas por error.
- Confirma una acción destructiva sin comprenderla cuando la interfaz lo facilita demasiado.
- Intenta restaurar o deshacer después.
- No debe ejecutar destrucción real fuera de un entorno autorizado.

## Administrador confundido

- Cambia ajustes incompatibles o en orden incorrecto.
- Prueba acciones administrativas con selección vacía o filtros activos inesperados.
- Abre URLs administrativas directamente.
- Alterna entre roles cuando el alcance autorizado lo permita.

## Usuario que intenta recuperarse

- Corrige datos después de un error.
- Cancela y reinicia el flujo.
- Recarga o vuelve a iniciar sesión.
- Comprueba si el sistema conserva trabajo válido y explica cómo continuar.
